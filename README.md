# 🧹 Data Cleaning Using Pandas

A beginner-friendly data cleaning project demonstrating how to clean, preprocess, and analyze real-world datasets using the **Pandas** library in Python. The project uses publicly available COVID-19 datasets to practice essential data preprocessing techniques required before performing data analysis or building machine learning models.

---

## 📌 Project Overview

Raw datasets often contain missing values, duplicate records, inconsistent formatting, and incorrect data types. This project showcases how to use **Pandas** to transform messy data into a clean and structured format suitable for analysis.

The notebook walks through common data cleaning operations while working with COVID-19 datasets from different sources.

---

## ✨ Features

* Load CSV datasets using Pandas
* Inspect dataset structure
* Handle missing values
* Remove duplicate records
* Rename columns
* Filter and sort data
* Convert data types
* Perform basic statistical analysis
* Explore and clean multiple datasets

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/jillasrivardhan/Data-cleaning-using-Pandas.git
```

### Navigate to the project

```bash
cd Data-cleaning-using-Pandas
```

### Install dependencies

```bash
pip install pandas jupyter
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open `pandas.ipynb` to explore the project.
